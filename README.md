# متابعة الحفظ والتثبيت والمراجعة

تطبيق ويب ثابت (PWA) بلغة HTML/CSS/JS بلا أي أدوات بناء، لمتابعة خطة الحفظ:

1. **الحفظ العقلي**: 9 تكرارات (3 استماعات مركزة، 3 نظرًا، 3 عن ظهر قلب).
2. **الحفظ اللساني**: أكثر من 30 تكرارًا.
3. **التكرار المتباعد**: مراجعة بعد 3 أيام، ثم 7 أيام، ثم شهر (كل فاصل يُحسب من المراجعة السابقة).
4. **الورد الأسبوعي**: تدخله السورة بعد إتمامها كاملة.

## الملفات

| الملف | الغرض |
|---|---|
| `index.html` | التطبيق كاملًا (واجهة ومنطق وأنماط) |
| `manifest.webmanifest` | بيانات التثبيت على الهاتف |
| `sw.js` | عامل الخدمة للعمل دون اتصال |
| `icons/` | الأيقونات |
| `netlify.toml` | إعدادات النشر والترويسات |

## التجربة محليًا

```bash
python3 -m http.server 8080
# ثم افتح http://localhost:8080
```

## النشر على Netlify

**من المستودع (موصى به):**
1. ارفع المجلد إلى GitHub.
2. في Netlify: Add new site ← Import an existing project ← اختر المستودع.
3. اترك أمر البناء فارغًا؛ مجلد النشر `.` (مضبوط في `netlify.toml`).

**أو بالسحب والإفلات:** اسحب المجلد في صفحة Sites على Netlify.

## التحديث

عدّل `index.html` ثم غيّر `VERSION` في `sw.js` (مثلًا `hifz-v2`) كي يتحدّث الكاش عند المستخدمين.

## البيانات

تُحفظ في `localStorage` داخل متصفح كل جهاز، ولا يُرسل شيء إلى خادم. للنقل بين الأجهزة استعمل «نسخ احتياطي واستعادة» أسفل الصفحة.
